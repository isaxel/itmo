# Карточки по архитектуре компьютера

Тренажёр экзаменационных билетов: **234 вопроса** курса «Архитектура компьютера» (2026.1 + 2026.2)
с развёрнутыми ответами, составленными по конспектам лекций. Одна сторона карточки — вопрос,
другая — ответ на 4–7 тезисов, рассчитанный на устный ответ за полминуты-минуту.

Приложение — обычная веб-страница без сервера, без сборщика и без зависимостей.
Прогресс («знаю» / «не знаю») хранится в браузере.

---

## старт

Откройте `dist/index.html` двойным кликом.
Работает офлайн, ничего устанавливать не нужно. Этот файл можно скинуть себе в мессенджер,
на флешку или в облако — он самодостаточен (внутри и стили, и логика, и все карточки).

---

## Лицензия и оговорка

Тексты ответов составлены по конспектам лекций курса и предназначены для подготовки к экзамену; проверяйте спорные места по первоисточнику — формулировки преподавателя всегда главнее.
