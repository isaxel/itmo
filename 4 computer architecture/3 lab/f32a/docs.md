# Документация по системе команд (ISA) F32a

Архитектура F32a — это набор команд, основанный на стеке, разработанный для образовательных целей. Данная документация содержит обзор команд, доступных в ISA F32a, их синтаксис и семантику.

## Обзор архитектуры

Архитектура F32a является 32-разрядной стековой архитектурой, вдохновленной системами Forth. Она включает:

- Два основных стека: стек данных и стек возврата
- Два регистра общего назначения: A и B
- Операции, ориентированные на стек, которые упрощают многие задачи программирования
- Режим расширенной арифметики (EAM) для операций с учетом переноса
- Флаг переноса для арифметических операций
- Адресуемый ввод-вывод

Эта стековая архитектура предлагает другую парадигму программирования по сравнению с регистровыми архитектурами, что делает её отличной для понимания альтернативных вычислительных моделей.

Комментарии в коде ассемблера F32a обозначаются символом `\`.

Вдохновлено [F18a](https://www.greenarraychips.com/home/documents/greg/DB001-221113-F18a.pdf)

## Специфические представления состояния ISA

- `A:dec`, `A:hex` -- регистр `A`.
- `B:dec`, `B:hex` -- регистр `B`.
- `T:dec`, `T:hex` -- вершина стека данных.
- `S:dec`, `S:hex` -- второе значение в стеке данных.
- `R:dec`, `R:hex` -- вершина стека возврата.
- `stack:dec`, `stack:hex` -- весь стек данных.
- `rstack:dec`, `rstack:hex` -- весь стек возврата.
- `EAM` -- режим расширенной арифметики (1 — включен, 0 — выключен).
- `C` -- флаг переноса (1 — установлен, 0 — сброшен).

### Использование стеков

Симулятор отслеживает максимальную глубину (наивысший достигнутый уровень) каждого стека за весь прогон и предоставляет их через две итоговые переменные представления. Они являются общепрогонными суммарными значениями, поэтому используйте их с `slice: last`.

- `f32a:data-stack-max` -- максимальная глубина стека данных, достигнутая во время выполнения.
- `f32a:return-stack-max` -- максимальная глубина стека возврата, достигнутая во время выполнения.

Пример -- вывод сводки по глубине стеков в конце симуляции:

```yaml
reports:
    - name: stacks
      slice: last
      view: |
        f32a:data-stack-max:   {f32a:data-stack-max}
        f32a:return-stack-max: {f32a:return-stack-max}
```

Для `factorial.s`, вычисляющего `4!`, сводка выглядит так:

```text
f32a:data-stack-max:   5
f32a:return-stack-max: 3
```

Глубина стека возврата отражает, насколько глубоко вложены рекурсивные/вложенные вызовы; глубина стека данных показывает, сколько операндов одновременно было активно -- полезно для определения размера области стека и обнаружения неконтролируемой рекурсии.

Обе строки также выводятся вместе общим блоком `{isa-specific}`, что позволяет использовать единый шаблон отчёта для всех ISA.

## Команды

Размер команды: 1 байт для кода операции, 4 байта для каждого аргумента.

### Режим расширенной арифметики (EAM)

Режим расширенной арифметики (EAM) — это режим, позволяющий выполнять сложение с учётом бита переноса. Подробности см. в команде `add`.

### Флаг переноса

Большинство команд сбрасывают (очищают) флаг переноса. В частности, любая команда, которая помещает значение в стек данных, побочно сбрасывает флаг переноса. Исключения: `add` (устанавливает флаг переноса на основе переполнения), `dup` (сохраняет флаг переноса).

### Команды перемещения данных

- **Литерал**
    - **Синтаксис:** `<значение>` или `lit <значение>`
    - **Описание:** Поместить непосредственное значение в стек данных. Ключевое слово `lit` необязательно — достаточно просто числа, шестнадцатеричного значения (`0xFF`) или символьного литерала (`'A'`).
    - **Операция:** `dataStack.push(<value>)`

- **Извлечение по адресу**
    - **Синтаксис:** `@p <address>`
    - **Описание:** Поместить значение из указанного адреса в стек данных.
    - **Операция:** `dataStack.push(mem[<address>])`

- **Извлечение**
    - **Синтаксис:** `@`
    - **Описание:** Поместить значение из адреса, хранящегося в регистре A, в стек данных.
    - **Операция:** `dataStack.push(mem[A])`

- **Извлечение с инкрементом**
    - **Синтаксис:** `@+`
    - **Описание:** Поместить значение из адреса в регистре A в стек данных и увеличить A.
    - **Операция:** `dataStack.push(mem[A]); A <- A + 1`

- **Извлечение B**
    - **Синтаксис:** `@b`
    - **Описание:** Поместить значение из адреса в регистре B в стек данных.
    - **Операция:** `dataStack.push(mem[B])`

- **Запись по адресу**
    - **Синтаксис:** `!p <address>`
    - **Описание:** Сохранить верхнее значение стека данных по указанному адресу.
    - **Операция:** `mem[<address>] <- dataStack.pop()`

- **Запись**
    - **Синтаксис:** `!`
    - **Описание:** Сохранить верхнее значение стека данных по адресу в регистре A.
    - **Операция:** `mem[A] <- dataStack.pop()`

- **Запись с инкрементом**
    - **Синтаксис:** `!+`
    - **Описание:** Сохранить верхнее значение стека данных по адресу в регистре A и увеличить A.
    - **Операция:** `mem[A] <- dataStack.pop(); A <- A + 1`

- **Запись B**
    - **Синтаксис:** `!b`
    - **Описание:** Сохранить верхнее значение стека данных по адресу в регистре B.
    - **Операция:** `mem[B] <- dataStack.pop()`

- **Запись в A**
    - **Синтаксис:** `a!`
    - **Описание:** Сохранить верхнее значение стека данных в регистр A.
    - **Операция:** `A <- dataStack.pop()`

- **Запись в B**
    - **Синтаксис:** `b!`
    - **Описание:** Сохранить верхнее значение стека данных в регистр B.
    - **Операция:** `B <- dataStack.pop()`

- **Извлечение A**
    - **Синтаксис:** `a`
    - **Описание:** Поместить значение регистра A в стек данных.
    - **Операция:** `dataStack.push(A)`

### Арифметические команды

- **Сложение**
    - **Синтаксис:** `+`
    - **Описание:** Сложить два верхних значения в стеке данных.
    - **Операция (без EAM):** `dataStack.push(dataStack.pop() + dataStack.pop()), установить флаг переноса`
    - **Операция (EAM):** `dataStack.push(dataStack.pop() + dataStack.pop() + carry), установить флаг переноса`

- **Шаг умножения**
    - **Синтаксис:** `+*`
    - **Описание:** Выполнить шаг умножения.
    - **Операция:** `T <- T + (if A[0] then S else 0); A <- A >> 1; if T[0] then A[31] <- 1 else A[31] <- 0; T <- T >> 1`

- **Шаг деления**
    - **Синтаксис:** `+/`
    - **Описание:** Выполнить один микро-шаг **деления с восстановлением остатка**.
        - Делимое -- `A`
        - Делитель -- `mem[B]`
        - Частичный остаток -- `S`
        - Частичное частное -- `T`
    - **Операция:**  
        1. `S <- S << 1`
        2. `if A[31] then S[0] <- 1`
        3. `A <- A << 1`
        4. `T <- T << 1`
        5. `if S >= mem[B] then`
            - `S <- S - mem[B]`
            - `T[0] <- 1`
    - [**Пример на Python**](https://github.com/ryukzak/wrench/blob/master/example/step-by-step-div.py)

- **Сдвиг влево**
    - **Синтаксис:** `2*`
    - **Описание:** Сдвинуть верхнее значение стека данных влево на один бит.
    - **Операция:** `dataStack.push(dataStack.pop() << 1)`

- **Сдвиг вправо**
    - **Синтаксис:** `2/`
    - **Описание:** Сдвинуть верхнее значение стека данных вправо на один бит с сохранением знака (арифметический сдвиг).
    - **Операция:** `dataStack.push(dataStack.pop() >> 1)`

- **Инверсия**
    - **Синтаксис:** `inv`
    - **Описание:** Инвертировать все биты верхнего значения стека данных.
    - **Операция:** `dataStack.push(~dataStack.pop())`

- **Установка режима расширенной арифметики**
    - **Синтаксис:** `eam`
    - **Описание:** Извлечь значение из стека данных и установить флаг EAM.
    - **Операция:** `eam <- dataStack.pop()`

### Побитовые команды

- **И**
    - **Синтаксис:** `and`
    - **Описание:** Выполнить побитовое И над двумя верхними значениями стека данных.
    - **Операция:** `dataStack.push(dataStack.pop() & dataStack.pop())`

- **Исключающее ИЛИ**
    - **Синтаксис:** `xor`
    - **Описание:** Выполнить побитовое исключающее ИЛИ над двумя верхними значениями стека данных.
    - **Операция:** `dataStack.push(dataStack.pop() ^ dataStack.pop())`

### Команды управления стеком

- **Удалить**
    - **Синтаксис:** `drop`
    - **Описание:** Удалить верхнее значение из стека данных.
    - **Операция:** `dataStack.pop()`

- **Дублировать**
    - **Синтаксис:** `dup`
    - **Описание:** Дублировать верхнее значение стека данных.
    - **Операция:** `dataStack.push(dataStack.top()), флаг переноса не изменяется`

- **Over**
    - **Синтаксис:** `over`
    - **Описание:** Скопировать второе значение стека данных на вершину, сдвигая стек данных.
    - **Операция:** `T <- dataStack.pop(); S <- dataStack.pop(); dataStack.push(S); dataStack.push(T); dataStack.push(S)`

### Команды управления потоком

- **Возврат**
    - **Синтаксис:** `;`
    - **Описание:** Вернуться из подпрограммы.
    - **Операция:** `p <- returnStack.pop()`

- **Вызов**
    - **Синтаксис:** `<метка>`
    - **Описание:** Вызвать подпрограмму по указанной метке.
    - **Операция:** `returnStack.push(p); p <- <label>`

- **Переход**
    - **Синтаксис:** `<метка> ;`
    - **Описание:** Перейти по указанной метке.
    - **Операция:** `p <- <label>`

- **Next**
    - **Синтаксис:** `next <метка>`
    - **Описание:** Организовать цикл к указанной метке, уменьшая R.
    - **Операция:**
        - `if R != 0 then`
            - `R <- R - 1`
            - `p <- <label>`
        - `else returnStack.pop()`

- **Если**
    - **Синтаксис:** `if <метка>`
    - **Описание:** Перейти по указанной метке, если верхнее значение стека данных равно нулю.
    - **Операция:** `if dataStack.pop() == 0 then p <- <label>`

- **Если минус**
    - **Синтаксис:** `-if <метка>`
    - **Описание:** Перейти по указанной метке, если верхнее значение стека данных неотрицательно.
    - **Операция:** `if dataStack.pop() >= 0 then p <- <label>`

- **Останов**
    - **Синтаксис:** `halt`
    - **Описание:** Остановить машину.

### Команды работы с регистрами

- **R в T**
    - **Синтаксис:** `r>`
    - **Описание:** Переместить верхнее значение стека возврата в стек данных.
    - **Операция:** `dataStack.push(returnStack.pop())`

- **T в R**
    - **Синтаксис:** `>r`
    - **Описание:** Переместить верхнее значение стека данных в стек возврата.
    - **Операция:** `returnStack.push(dataStack.pop())`
