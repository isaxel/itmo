# Документация по системе команд Acc32 (ISA)

Система команд Acc32 представляет собой простую архитектуру на основе аккумулятора, разработанную для образовательных целей. Данная документация содержит обзор команд, их синтаксис и семантику.

## Обзор архитектуры

Архитектура Acc32 является 32-разрядной и построена на основе аккумулятора. Её особенности:

- Один регистр общего назначения — аккумулятор (Acc)
- Два флага состояния: переполнение (V) и перенос (C)
- Организация ввода-вывода с отображением на память
- Простой набор команд, ориентированных на операции с аккумулятором

Эта архитектура отлично подходит для начинающих, чтобы понять основы устройства компьютеров без сложностей, связанных с множеством регистров.

Комментарии в коде на ассемблере Acc32 обозначаются символом `;`.

## Представления состояния ISA

- `Acc:dec`, `Acc:hex` — регистр `Acc`.
- `V` — флаг переполнения.
- `C` — флаг переноса.

## Команды

Размер команды: 1 байт для кода операции, 4 байта для абсолютного операнда, 2 байта для относительного операнда. Команды управления потоком, загрузки/сохранения непосредственные/косвенные/по адресу используют абсолютный адрес, остальные — относительный.

### Команды перемещения данных

- **Загрузка непосредственного значения**
  - **Синтаксис:** `load_imm <value>`
  - **Описание:** Загрузить непосредственное значение в аккумулятор.
  - **Действие:** `acc <- <value>`
- **Загрузка**
  - **Синтаксис:** `load <offset>`
  - **Описание:** Загрузить значение из относительного адреса в аккумулятор.
  - **Действие:** `acc <- mem[pc + <offset>]`
- **Сохранение**
  - **Синтаксис:** `store <offset>`
  - **Описание:** Сохранить значение аккумулятора по относительному адресу.
  - **Действие:** `mem[pc + <offset>] <- acc`
- **Загрузка по адресу**
  - **Синтаксис:** `load_addr <address>`
  - **Описание:** Загрузить значение из конкретного адреса в аккумулятор.
  - **Действие:** `acc <- mem[<address>]`
- **Сохранение по адресу**
  - **Синтаксис:** `store_addr <address>`
  - **Описание:** Сохранить значение аккумулятора по конкретному адресу.
  - **Действие:** `mem[<address>] <- acc`
- **Загрузка по адресу в аккумуляторе**
  - **Синтаксис:** `load_acc`
  - **Описание:** Загрузить значение из адреса, хранящегося в аккумуляторе, в сам аккумулятор.
  - **Действие:** `acc <- mem[acc]`
- **Косвенное сохранение**
  - **Синтаксис:** `store_ind <address>`
  - **Описание:** Сохранить значение аккумулятора по косвенному адресу.
  - **Действие:** `mem[mem[<address>]] <- acc`

### Арифметические команды

- **Сложение**
  - **Синтаксис:** `add <address>`
  - **Описание:** Сложить значение из конкретного адреса с аккумулятором.
  - **Действие:** `acc <- acc + mem[<address>]` и установка флагов `C` и `V`.
- **Вычитание**
  - **Синтаксис:** `sub <address>`
  - **Описание:** Вычесть значение из конкретного адреса из аккумулятора.
  - **Действие:** `acc <- acc - mem[<address>]` и установка флагов `C` и `V`.
- **Умножение**
  - **Синтаксис:** `mul <address>`
  - **Описание:** Умножить аккумулятор на значение из конкретного адреса.
  - **Действие:** `acc <- acc * mem[<address>]` и установка флагов `C` и `V`.
- **Деление**
  - **Синтаксис:** `div <address>`
  - **Описание:** Разделить аккумулятор на значение из конкретного адреса.
  - **Действие:** `acc <- acc / mem[<address>]`
- **Остаток от деления**
  - **Синтаксис:** `rem <address>`
  - **Описание:** Вычислить остаток от деления аккумулятора на значение из конкретного адреса.
  - **Действие:** `acc <- acc % mem[<address>]`
- **Сброс флага переполнения**
  - **Синтаксис:** `clv`
  - **Описание:** Очистить флаг переполнения.
  - **Действие:** `overflow <- 0`
- **Сброс флага переноса**
  - **Синтаксис:** `clc`
  - **Описание:** Очистить флаг переноса.
  - **Действие:** `carry <- 0`

### Побитовые команды

- **Сдвиг влево**
  - **Синтаксис:** `shiftl <address>`
  - **Описание:** Сдвинуть аккумулятор влево на количество бит, заданное значением из конкретного адреса (флаг переноса не используется).
  - **Действие:** `acc <- acc << mem[<address>]`
- **Сдвиг вправо**
  - **Синтаксис:** `shiftr <address>`
  - **Описание:** Сдвинуть аккумулятор вправо на количество бит, заданное значением из конкретного адреса, с сохранением знака (флаг переноса не используется).
  - **Действие:** `acc <- acc >> mem[<address>]`
- **Побитовое И**
  - **Синтаксис:** `and <address>`
  - **Описание:** Выполнить побитовое И над аккумулятором и значением из конкретного адреса.
  - **Действие:** `acc <- acc & mem[<address>]`
- **Побитовое ИЛИ**
  - **Синтаксис:** `or <address>`
  - **Описание:** Выполнить побитовое ИЛИ над аккумулятором и значением из конкретного адреса.
  - **Действие:** `acc <- acc | mem[<address>]`
- **Побитовое исключающее ИЛИ**
  - **Синтаксис:** `xor <address>`
  - **Описание:** Выполнить побитовое XOR над аккумулятором и значением из конкретного адреса.
  - **Действие:** `acc <- acc ^ mem[<address>]`
- **Побитовое НЕ**
  - **Синтаксис:** `not`
  - **Описание:** Выполнить побитовое НЕ над аккумулятором.
  - **Действие:** `acc <- ~acc`

### Команды управления потоком

- **Переход**
  - **Синтаксис:** `jmp <address>`
  - **Описание:** Перейти на конкретный адрес.
  - **Действие:** `pc <- <address>`
- **Переход, если равно нулю**
  - **Синтаксис:** `beqz <address>`
  - **Описание:** Перейти на конкретный адрес, если аккумулятор равен нулю.
  - **Действие:** `if acc == 0 then pc <- <address>`
- **Переход, если не равно нулю**
  - **Синтаксис:** `bnez <address>`
  - **Описание:** Перейти на конкретный адрес, если аккумулятор не равен нулю.
  - **Действие:** `if acc != 0 then pc <- <address>`
- **Переход, если больше нуля**
  - **Синтаксис:** `bgtz <address>`
  - **Описание:** Перейти на конкретный адрес, если аккумулятор больше нуля.
  - **Действие:** `if acc > 0 then pc <- <address>`
- **Переход, если больше или равно нулю**
  - **Синтаксис:** `bgez <address>`
  - **Описание:** Перейти на конкретный адрес, если аккумулятор больше или равен нулю.
  - **Действие:** `if acc >= 0 then pc <- <address>`
- **Переход, если меньше нуля**
  - **Синтаксис:** `bltz <address>`
  - **Описание:** Перейти на конкретный адрес, если аккумулятор меньше нуля.
  - **Действие:** `if acc < 0 then pc <- <address>`
- **Переход, если флаг переполнения установлен**
  - **Синтаксис:** `bvs <address>`
  - **Описание:** Перейти на конкретный адрес, если флаг переполнения установлен.
  - **Действие:** `if overflow == 1 then pc <- <address>`
- **Переход, если флаг переполнения сброшен**
  - **Синтаксис:** `bvc <address>`
  - **Описание:** Перейти на конкретный адрес, если флаг переполнения сброшен.
  - **Действие:** `if overflow == 0 then pc <- <address>`
- **Переход, если флаг переноса установлен**
  - **Синтаксис:** `bcs <address>`
  - **Описание:** Перейти на конкретный адрес, если флаг переноса установлен.
  - **Действие:** `if carry == 1 then pc <- <address>`
- **Переход, если флаг переноса сброшен**
  - **Синтаксис:** `bcc <address>`
  - **Описание:** Перейти на конкретный адрес, если флаг переноса сброшен.
  - **Действие:** `if carry == 0 then pc <- <address>`
- **Останов**
  - **Синтаксис:** `halt`
  - **Описание:** Остановить машину.
