.byte — выделяет 1 байт (например, символ 'A').

.word — выделяет 4 байта (16ти или 32-битное число).

.space N — выделяет N байт, но не инициализирует их (оставляет мусор или нули, зависит от ассемблера)


_start (с подчеркиванием) — это стандартное имя точки входа, которое по умолчанию ищет линковщик в большинстве Unix-подобных систем (Linux, BSD и т.д.) и в тулчейне GNU.

start (без подчеркивания) — это обычная пользовательская метка, которая не имеет специального статуса для линковщика; если вы сделаете её точкой входа, придётся явно указывать линковщику, с какого адреса начинать выполнение.


Когда мы прибавляем текущее слово cur к аккумулятору, мы фактически делаем это:

```
(sum_hi : sum_lo) + (0x00000000 : cur) — если cur >= 0
(sum_hi : sum_lo) + (0xFFFFFFFF : cur) — если cur < 0
```

Программа делает это в два прохода:

Сначала складываются младшие 32 бита: sum_lo + cur.
При этом возникает флаг переноса C (carry), если результат ≥ 2³².

Затем складываются старшие 32 бита.
В старшую часть нужно прибавить:

+ 0 (если переноса не было) или + 1 (если перенос был) — это мы делаем командой add const_1.
 
Плюс нужно добавить те самые «лишние» старшие биты расширенного слова. Для отрицательного cur это 0xFFFFFFFF, для положительного — 0x00000000.
