# Документация по системе команд M68k (ISA)

Система команд M68k представляет собой простую CISC-подобную архитектуру, вдохновлённую архитектурой Motorola 68000. Данная документация содержит обзор команд, доступных в ISA M68k, их синтаксис и семантику.

## Обзор архитектуры

Архитектура M68k является 32-разрядной CISC-архитектурой (Complex Instruction Set Computer), вдохновлённой серией Motorola 68000. Она включает:

- 8 регистров данных общего назначения (D0–D7)
- 8 адресных регистров (A0–A7, причём A7 также используется как указатель стека)
- Разнообразные режимы адресации для гибкого доступа к памяти
- Богатый набор команд с несколькими размерами операндов
- Регистр состояния с флагами условий
- Отображённые на память устройства ввода-вывода

Данная архитектура обеспечивает баланс между простотой RISC-решений и насыщенностью возможностей CISC-процессоров, что делает её отличной платформой для изучения более сложных конструкций процессоров.

Комментарии в коде на ассемблере M68k обозначаются символом `;`.

- [Wiki: Motorola 68000](https://en.wikipedia.org/wiki/Motorola_68000)

## Представления состояния ISA

- `D<n>:dec`, `D<n>:hex` – Регистры данных (D0–D7).
- `A<n>:dec`, `A<n>:hex` – Адресные регистры (A0–A7).
- `PC:dec`, `PC:hex` – Счётчик команд.
- `SR:bin` – Регистр состояния (флаги: N, Z, V, C).

### Использование памяти и регистров

- **Регистры данных (D0–D7):** Регистры общего назначения для арифметических, логических операций и манипуляций с данными.
- **Адресные регистры (A0–A7):** Используются для адресации памяти. A7 также является указателем стека (SP).
- **Регистр состояния (SR):** Содержит коды условий (флаги):
    - **N (Negative):** Устанавливается, если результат операции отрицательный.
    - **Z (Zero):** Устанавливается, если результат операции равен нулю.
    - **V (Overflow):** Устанавливается при арифметическом переполнении.
    - **C (Carry):** Устанавливается при возникновении переноса или заёма в арифметических операциях.

## Команды

Размеры команд варьируются в зависимости от режима операции и используемых режимов адресации. Вычисление размера байта теперь учитывает различия между байтовыми и длинными операциями, причём байтовые операции обычно занимают меньше памяти, чем длинные.

### Режимы операций

Команды M68k могут работать с данными разных размеров:

- **Байт (`.b`):** 8-разрядные операции
- **Длинное слово (`.l`):** 32-разрядные операции

Суффикс размера обязателен и должен быть явно указан для всех команд, которые его поддерживают.

Пример: `add.b D0, D1` работает с младшим байтом D0 и D1.

> **Примечание о реализации ByteSize:** Реализация ByteSize для команд теперь различает байтовые и длинные операции. Байтовые операции (`.b`) используют 1 байт для данных, в то время как длинные операции (`.l`) используют 4 байта. Все команды переходов и ветвлений всегда используют длинные (6-байтовые) кодировки, независимо от смещения.

### Режимы адресации

ISA M68k поддерживает следующие режимы адресации:

1. **Прямая регистровая**
   - **Прямая регистровая данных**: `D0` – `D7` – могут использоваться как источник или приёмник для любой команды, принимающей операнд.
   - **Прямая адресно-регистровая**: `A0` – `A7` – могут использоваться только как источник/приёмник для `movea` и как операнд адресного регистра для `link`/`unlk`. Другие команды отвергают `An` в слоте операнда с ошибкой парсера; чтобы получить значение адресного регистра, сначала используйте `movea`, либо один из косвенных режимов ниже.

2. **Непосредственная**: `значение`
   - Пример: `move.l 42, D0`

3. **Адресация памяти**
   - **Косвенная адресация через адресный регистр**: `(An)`
     - Обращение к памяти по адресу, содержащемуся в An
     - Пример: `move.l (A0), D0`

   - **Косвенная адресация через адресный регистр с автоинкрементом после**: `(An)+`
     - Использует адрес из An, затем увеличивает An на размер операции (1 для байта, 4 для длинного)
     - Пример: `move.l (A0)+, D0`

   - **Косвенная адресация через адресный регистр с автодекрементом перед**: `-(An)`
     - Уменьшает An на размер операции, затем использует полученный адрес
     - Пример: `move.l -(A0), D0`

   - **Косвенная адресация через адресный регистр со смещением**: `d(An)`
     - Использует адрес из An плюс знаковое 16-разрядное смещение d
     - Пример: `move.l 8(A0), D0` или `move.l -4(A0), D0`

   - **Косвенная адресация через адресный регистр с индексом**: `d(An,Xn)`
     - Использует адрес из An плюс значение Xn (может быть регистром данных или адресным регистром) плюс знаковое смещение d
     - Пример: `move.l 4(A0,D1), D0` или `move.l 8(A0,A1), D0`

### Команды перемещения данных

- **Move**
    - **Синтаксис:** `move.<size> <source>, <destination>`
    - **Описание:** Перемещает данные из источника в приёмник. Устанавливает флаги N и Z на основе результата, сбрасывает флаги V и C.
    - **Операция:** `<destination> <- <source>`
    - **Примеры:**

      ```assembly
      move.l D0, D1       ; Копировать D0 в D1 (32-бит)
      move.b D0, D1       ; Копировать младший байт из D0 в младший байт D1
      move.l 42, D0       ; Загрузить непосредственное значение 42 в D0
      move.l (A0), D0     ; Загрузить значение из памяти по адресу в A0 в D0
      move.l D0, (A1)     ; Сохранить значение из D0 в память по адресу в A1
      move.l (A0)+, D0    ; Загрузить значение из A0, затем увеличить A0 на 4
      move.l -(A0), D0    ; Уменьшить A0 на 4, затем загрузить значение из A0
      move.l 8(A0), D0    ; Загрузить значение из A0+8
      move.l -4(A0), D0   ; Загрузить значение из A0-4
      move.l 8(A0,D1), D0 ; Загрузить значение из A0+D1+8
      move.l 4(A0,A1), D0 ; Загрузить значение из A0+A1+4
      ```

- **Move в адресный регистр**
    - **Синтаксис:** `movea.l <source>, <destination>`
    - **Описание:** Перемещает данные из источника в адресный регистр назначения. `movea` – единственная команда, которая принимает `An` как прямой операнд-источник – остальные команды отвергают `An` на этапе парсинга. `movea` работает только с длинными словами (нет формы `.b`). Не влияет на флаги.
    - **Операция:** `<destination> <- <source>`
    - **Примеры:**

      ```assembly
      movea.l 1000, A0    ; Загрузить непосредственное значение 1000 в A0
      movea.l D0, A1      ; Копировать D0 в A1
      movea.l A2, A0      ; Копировать A2 в A0 (единственное место, где An принимается как источник)
      ```

### Логические команды

- **Clear**
    - **Синтаксис:** `clr.<size> <destination>`
    - **Описание:** Обнуляет приёмник. Устанавливает флаг Z, сбрасывает N, V и C.
    - **Операция:** `<destination> <- 0`
    - **Примеры:**

      ```assembly
      clr.l D0            ; D0 <- 0 (32-бит)
      clr.b D0            ; Очистить младший байт D0
      ```

- **Negate**
    - **Синтаксис:** `neg.<size> <destination>`
    - **Описание:** Изменяет знак приёмника (вычисляет 0 – приёмник). Устанавливает флаги N, Z, V и C на основе результата.
    - **Операция:** `<destination> <- 0 - <destination>`
    - **Примеры:**

      ```assembly
      neg.l D0            ; D0 <- -D0 (32-бит)
      neg.b D0            ; Изменить знак младшего байта D0
      ```

- **Not**
    - **Синтаксис:** `not.<size> <destination>`
    - **Описание:** Побитовое НЕ приёмника. Устанавливает флаги N и Z на основе результата, сбрасывает V и C.
    - **Операция:** `<destination> <- ~<destination>`
    - **Примеры:**

      ```assembly
      not.l D0            ; D0 <- ~D0 (32-бит)
      not.b D0            ; Применить НЕ к младшему байту D0
      ```

- **And**
    - **Синтаксис:** `and.<size> <source>, <destination>`
    - **Описание:** Побитовое И источника с приёмником. Устанавливает флаги N и Z на основе результата, сбрасывает V и C.
    - **Операция:** `<destination> <- <destination> & <source>`
    - **Примеры:**

      ```assembly
      and.l D0, D1        ; D1 <- D1 & D0 (32-бит)
      and.b D0, D1        ; И над младшими байтами D0 и D1
      ```

- **Or**
    - **Синтаксис:** `or.<size> <source>, <destination>`
    - **Описание:** Побитовое ИЛИ источника с приёмником. Устанавливает флаги N и Z на основе результата, сбрасывает V и C.
    - **Операция:** `<destination> <- <destination> | <source>`
    - **Примеры:**

      ```assembly
      or.l D0, D1         ; D1 <- D1 | D0 (32-бит)
      or.b D0, D1         ; ИЛИ над младшими байтами D0 и D1
      ```

- **Exclusive Or**
    - **Синтаксис:** `xor.<size> <source>, <destination>`
    - **Описание:** Побитовое исключающее ИЛИ источника с приёмником. Устанавливает флаги N и Z на основе результата, сбрасывает V и C.
    - **Операция:** `<destination> <- <destination> ^ <source>`
    - **Примеры:**

      ```assembly
      xor.l D0, D1        ; D1 <- D1 ^ D0 (32-бит)
      xor.b D0, D1        ; XOR над младшими байтами D0 и D1
      ```

### Арифметические команды

- **Add**
    - **Синтаксис:** `add.<size> <source>, <destination>`
    - **Описание:** Сложение источника и приёмника.
    - **Операция:** `<destination> <- <destination> + <source>`
    - **Примеры:**

      ```assembly
      add.l D0, D1        ; D1 <- D1 + D0 (32-бит)
      add.b D0, D1        ; Сложить младшие байты D0 и D1
      add.l 10, D0        ; D0 <- D0 + 10
      add.b 5, D0         ; Прибавить 5 к младшему байту D0
      ```

- **Subtract**
    - **Синтаксис:** `sub.<size> <source>, <destination>`
    - **Описание:** Вычитание источника из приёмника.
    - **Операция:** `<destination> <- <destination> - <source>`
    - **Примеры:**

      ```assembly
      sub.l D0, D1        ; D1 <- D1 - D0 (32-бит)
      sub.b D0, D1        ; Вычесть младший байт D0 из младшего байта D1
      sub.l 1, D0         ; D0 <- D0 - 1
      sub.b 1, D0         ; Вычесть 1 из младшего байта D0
      ```

- **Compare**
    - **Синтаксис:** `cmp.<size> <source>, <destination>`
    - **Описание:** Сравнивает приёмник с источником путём вычитания источника из приёмника и установки кодов условий соответственно, без сохранения результата.
    - **Операция:** `temp <- <destination> - <source>` (устанавливает только флаги)
    - **Примеры:**

      ```assembly
      cmp.l D0, D1        ; Сравнить D1 с D0 (32-бит)
      cmp.b D0, D1        ; Сравнить младшие байты D1 и D0
      cmp.l 10, D0        ; Сравнить D0 с непосредственным значением 10
      cmp.b 5, D0         ; Сравнить младший байт D0 с 5
      cmp.l (A0), D0      ; Сравнить D0 с памятью по адресу в A0
      ```

- **Multiply**
    - **Синтаксис:** `mul.<size> <source>, <destination>`
    - **Описание:** Умножает приёмник на источник.
    - **Операция:** `<destination> <- <destination> * <source>`
    - **Примеры:**

      ```assembly
      mul.l D0, D1        ; D1 <- D1 * D0 (32-бит)
      mul.b D0, D1        ; Умножить младшие байты D0 и D1
      ```

- **Divide**
    - **Синтаксис:** `div.<size> <source>, <destination>`
    - **Описание:** Делит приёмник на источник.
    - **Операция:** `<destination> <- <destination> / <source>`
    - **Примеры:**

      ```assembly
      div.l D0, D1        ; D1 <- D1 / D0 (32-бит)
      div.b D0, D1        ; Деление с использованием младших байтов регистров
      ```

### Команды сдвига и вращения

- **Арифметический сдвиг влево**
    - **Синтаксис:** `asl.<size> <source>, <destination>`
    - **Описание:** Арифметический сдвиг приёмника влево на количество, заданное в источнике. Устанавливает флаги N и Z на основе результата, флаг C устанавливается в последний выдвинутый бит (0, если сдвиг на 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> << <source>`
    - **Примеры:**

      ```assembly
      asl.l 2, D0         ; D0 <- D0 << 2 (32-бит)
      asl.b 2, D0         ; Сдвинуть младший байт D0 влево на 2 бита
      asl.l D1, D0        ; D0 <- D0 << D1
      ```

- **Арифметический сдвиг вправо**
    - **Синтаксис:** `asr.<size> <source>, <destination>`
    - **Описание:** Арифметический сдвиг приёмника вправо на количество, заданное в источнике. Устанавливает флаги N и Z на основе результата, флаг C устанавливается в последний выдвинутый бит (0, если сдвиг на 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> >> <source>` (с сохранением знака)
    - **Примеры:**

      ```assembly
      asr.l 2, D0         ; D0 <- D0 >> 2 (32-бит)
      asr.b 2, D0         ; Сдвинуть младший байт D0 вправо на 2 бита
      asr.l D1, D0        ; D0 <- D0 >> D1
      ```

- **Логический сдвиг влево**
    - **Синтаксис:** `lsl.<size> <source>, <destination>`
    - **Описание:** Логический сдвиг приёмника влево на количество, заданное в источнике. Устанавливает флаги N и Z на основе результата, флаг C устанавливается в последний выдвинутый бит (0, если сдвиг на 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> << <source>`
    - **Примеры:**

      ```assembly
      lsl.l 2, D0         ; D0 <- D0 << 2 (32-бит)
      lsl.b 2, D0         ; Сдвинуть младший байт D0 влево на 2 бита
      lsl.l D1, D0        ; D0 <- D0 << D1
      ```

- **Логический сдвиг вправо**
    - **Синтаксис:** `lsr.<size> <source>, <destination>`
    - **Описание:** Логический сдвиг приёмника вправо на количество, заданное в источнике. Устанавливает флаги N и Z на основе результата, флаг C устанавливается в последний выдвинутый бит (0, если сдвиг на 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> >> <source>` (заполнение нулями)
    - **Примеры:**

      ```assembly
      lsr.l 2, D0         ; D0 <- D0 >> 2 (32-бит)
      lsr.b 2, D0         ; Сдвинуть младший байт D0 вправо на 2 бита
      lsr.l D1, D0        ; D0 <- D0 >> D1
      ```

### Команды управления потоком

- **Jump**
    - **Синтаксис:** `jmp <label>`
    - **Описание:** Переход на указанную метку.
    - **Операция:** `PC <- <label>`
    - **Примеры:**

      ```assembly
      jmp loop            ; Перейти на метку "loop"
      ```

- **Ветвление, если перенос сброшен**
    - **Синтаксис:** `bcc <label>`
    - **Описание:** Переход на указанную метку, если флаг переноса сброшен.
    - **Операция:** `if C == 0 then PC <- <label>`
    - **Примеры:**

      ```assembly
      bcc loop            ; Перейти на "loop", если флаг C сброшен
      ```

- **Ветвление, если перенос установлен**
    - **Синтаксис:** `bcs <label>`
    - **Описание:** Переход на указанную метку, если флаг переноса установлен.
    - **Операция:** `if C == 1 then PC <- <label>`
    - **Примеры:**

      ```assembly
      bcs error           ; Перейти на "error", если флаг C установлен
      ```

- **Ветвление, если равно**
    - **Синтаксис:** `beq <label>`
    - **Описание:** Переход на указанную метку, если флаг нуля установлен.
    - **Операция:** `if Z == 1 then PC <- <label>`
    - **Примеры:**

      ```assembly
      beq done            ; Перейти на "done", если флаг Z установлен
      ```

- **Ветвление, если не равно**
    - **Синтаксис:** `bne <label>`
    - **Описание:** Переход на указанную метку, если флаг нуля сброшен.
    - **Операция:** `if Z == 0 then PC <- <label>`
    - **Примеры:**

      ```assembly
      bne loop            ; Перейти на "loop", если флаг Z сброшен
      ```

- **Ветвление, если меньше**
    - **Синтаксис:** `blt <label>`
    - **Описание:** Переход на указанную метку, если N ≠ V.
    - **Операция:** `if N != V then PC <- <label>`
    - **Примеры:**

      ```assembly
      blt less            ; Перейти на "less", если результат меньше
      ```

- **Ветвление, если больше**
    - **Синтаксис:** `bgt <label>`
    - **Описание:** Переход на указанную метку, если Z = 0 и N = V.
    - **Операция:** `if Z == 0 and N == V then PC <- <label>`
    - **Примеры:**

      ```assembly
      bgt greater         ; Перейти на "greater", если результат больше
      ```

- **Ветвление, если меньше или равно**
    - **Синтаксис:** `ble <label>`
    - **Описание:** Переход на указанную метку, если Z = 1 или N ≠ V.
    - **Операция:** `if Z == 1 or N != V then PC <- <label>`
    - **Примеры:**

      ```assembly
      ble less_or_equal   ; Перейти на "less_or_equal", если результат меньше или равен
      ```

- **Ветвление, если больше или равно**
    - **Синтаксис:** `bge <label>`
    - **Описание:** Переход на указанную метку, если N = V.
    - **Операция:** `if N == V then PC <- <label>`
    - **Примеры:**

      ```assembly
      bge greater_or_equal ; Перейти на "greater_or_equal", если результат больше или равен
      ```

- **Ветвление, если минус**
    - **Синтаксис:** `bmi <label>`
    - **Описание:** Переход на указанную метку, если флаг отрицания установлен.
    - **Операция:** `if N == 1 then PC <- <label>`
    - **Примеры:**

      ```assembly
      bmi negative        ; Перейти на "negative", если результат отрицательный
      ```

- **Ветвление, если плюс**

- **Переход к подпрограмме**

- **Возврат из подпрограммы**
    - **Синтаксис:** `rts`
    - **Описание:** Возврат из подпрограммы путём извлечения адреса возврата из стека и перехода на него.
    - **Операция:** Извлечь PC из стека
    - **Примеры:**

      ```assembly
      rts                ; Вернуться из подпрограммы
      ```

- **Link**
    - **Синтаксис:** `link <address_register>, <offset>`
    - **Описание:** Создаёт стековый кадр для подпрограммы, устанавливая новый указатель кадра и выделяя место в стеке для локальных переменных. Команда `link` обычно используется в начале функции для настройки окружения для хранения локальных переменных.
    - **Детальная работа:**
      1. Поместить текущее значение указанного адресного регистра (обычно A6, используется как указатель кадра) в стек
      2. Скопировать текущее значение указателя стека (A7) в указанный адресный регистр, устанавливая новый указатель кадра
      3. Добавить значение смещения к указателю стека (A7) для резервирования места под локальные переменные
         - Смещение должно быть отрицательным для выделения места (например, -4 выделяет 4 байта)
         - Доступ к локальным переменным затем можно получить по отрицательным смещениям от указателя кадра
    - **Контекст использования:**
        - Обычно используется с A6 в качестве стандартного регистра указателя кадра
        - Локальные переменные доступны через указатель кадра с отрицательными смещениями (например, `-4(A6)`)
        - Параметры, переданные через стек, доступны по положительным смещениям (например, `8(A6)`)
    - **Примеры:**

      ```assembly
      link A6, -8        ; Сохранить старый A6 в стеке, установить A6 = SP, вычесть 8 из SP для выделения места
      move.l D0, -4(A6)  ; Сохранить D0 в первую локальную переменную (4 байта от указателя кадра)
      move.l D1, -8(A6)  ; Сохранить D1 во вторую локальную переменную (8 байт от указателя кадра)
      ```

- **Unlink**
    - **Синтаксис:** `unlk <address_register>`
    - **Описание:** Освобождает стековый кадр в конце подпрограммы, восстанавливая указатель стека и указатель кадра в значения, которые были до выполнения соответствующей команды `link`. Команда `unlk` обычно является последней операцией перед возвратом из функции.
    - **Детальная работа:**
      1. Скопировать указатель кадра (указанный адресный регистр, обычно A6) в указатель стека (A7)
         - Это фактически удаляет все локальные переменные, восстанавливая указатель стека в позицию до выделения
      2. Извлечь значение из вершины стека в указанный адресный регистр
         - Это восстанавливает предыдущее значение указателя кадра, сохранённое командой `link`
    - **Контекст использования:**
        - Всегда используется в паре с соответствующей командой `link`
        - Обычно за ней следует команда `rts` (возврат из подпрограммы)
        - Корректно освобождает все локальные переменные, созданные в функции
    - **Примеры:**

      ```assembly
      unlk A6            ; Установить SP = A6 (освобождение локальных), затем извлечь сохранённый указатель кадра в A6
      rts                ; Вернуться из подпрограммы
      ```

      Полный пример функции:

      ```assembly
      my_function:
          link A6, -12         ; Создать стековый кадр с 12 байтами для локальных переменных
          move.l 8(A6), D0     ; Получить доступ к параметру, переданному через стек (по положительному смещению)
          move.l D0, -4(A6)    ; Сохранить в локальную переменную (по отрицательному смещению)
          ; ... тело функции ...
          unlk A6              ; Уничтожить стековый кадр
          rts                  ; Вернуться из подпрограммы
      ```
