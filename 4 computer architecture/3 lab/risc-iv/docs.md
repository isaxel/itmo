# Документация по системе команд RISC-IV (ISA)

Система команд RISC-IV представляет собой простую архитектуру с регистровым набором команд, вдохновлённую архитектурой RISC‑V. Данная документация содержит обзор инструкций, доступных в ISA RISC‑IV, их синтаксис и семантику.

## Обзор архитектуры

Архитектура RISC‑IV является 32‑разрядной RISC‑архитектурой (Reduced Instruction Set Computer), созданной по образцу спецификации RISC‑V. Она включает:

- 32 регистра общего назначения (включая один аппаратно занулённый регистр — запись в `Zero` игнорируется);
- команды фиксированной длины — 4 байта;
- архитектуру загрузки‑сохранения (доступ к памяти только через специальные инструкции);
- простые режимы адресации;
- память с отображением на ввод‑вывод;
- поддержку вызовов функций и возвратов через инструкции переходов с сохранением адреса возврата;
- арифметические, логические операции и операции управления потоком.

Эта архитектура предоставляет чистый, ортогональный набор команд, иллюстрирующий принципы RISC‑проектирования, что делает её отличной для образовательных целей, но при этом достаточно мощной для практических приложений.

Комментарии в ассемблерном коде RISC‑IV обозначаются символом `;`.

Вдохновлено [RISC‑V](https://riscv.org/wp-content/uploads/2017/05/riscv-spec-v2.2.pdf)

### Соглашения об использовании регистров

Хотя технически большинство регистров можно использовать для любых целей, рекомендуются следующие соглашения:

| Регистр(ы) | Назначение                                                                             | Соглашение       |
| ---------- | -------------------------------------------------------------------------------------- | ---------------- |
| `Zero`     | Константный ноль. Записи игнорируются.                                                 | Сохраняемый      |
| `Ra`       | Адрес возврата для вызовов функций.                                                    | Вызывающий‑сохраняемый |
| `Sp`       | Указатель стека.                                                                       | Вызываемый‑сохраняемый |
| `Gp`       | Глобальный указатель. Указывает на область с часто используемыми глобальными данными. | Вызываемый‑сохраняемый |
| `Tp`       | Указатель потока. Зарезервирован для данных, локальных для потока.                    | Вызываемый‑сохраняемый |
| `A0‑A7`    | Аргументы функций и возвращаемые значения.                                             | Вызывающий‑сохраняемый |
| `T0‑T6`    | Временные регистры для промежуточных вычислений.                                       | Вызывающий‑сохраняемый |
| `S0Fp`     | Указатель кадра или сохраняемый регистр.                                               | Вызываемый‑сохраняемый |
| `S1‑S11`   | Сохраняемые регистры для долгоживущих значений.                                        | Вызываемый‑сохраняемый |

**Вызывающий‑сохраняемые** регистры могут свободно изменяться вызываемой функцией. Если вызывающему коду необходимы их значения после вызова функции, он должен сохранить и восстановить их.

**Вызываемый‑сохраняемые** регистры должны сохранять свои значения при вызовах функций. Функция, изменяющая вызываемый‑сохраняемый регистр, обязана восстановить его исходное значение перед возвратом.

## Директивы для подстановки старших и младших частей Immediate

В ассемблере RISC‑IV предусмотрены специальные директивы для работы с большими непосредственными значениями, которые не помещаются в стандартные форматы команд:

- **%hi(символ)**
    - **Описание:** Используется для извлечения старших 20 бит 32‑разрядного адреса или непосредственного значения.
    - **Применение:** `lui rd, %hi(символ)`
    - **Действие:** `rd <- (символ & 0xFFFFF000)`

- **%lo(символ)**
    - **Описание:** Используется для извлечения младших 12 бит 32‑разрядного адреса или непосредственного значения.
    - **Применение:** `addi rd, rs, %lo(символ)`
    - **Действие:** `rd <- rs + (символ & 0x00000FFF)`

Обычно эти директивы используются вместе для загрузки полного 32‑разрядного адреса в регистр:

```assembly
lui  a0, %hi(address)    ; Загрузить старшие 20 бит в a0
addi a0, a0, %lo(address) ; Добавить младшие 12 бит к a0
```

## Инструкции

Размер инструкции: 4 байта.

### Инструкции перемещения данных

- **Load Upper Immediate**
    - **Синтаксис:** `lui <rd>, <k>`
    - **Описание:** Загружает непосредственное значение, ограниченное 20 битами и сдвинутое влево на 12 бит, в регистр назначения.
    - **Действие:** `rd <- (k & 0x000FFFFF) << 12`

- **Move**
    - **Синтаксис:** `mv <rd>, <rs>`
    - **Описание:** Копирует значение из регистра источника в регистр назначения.
    - **Действие:** `rd <- rs`

- **Store Word**
    - **Синтаксис:** `sw <rs2>, <offset>(<rs1>)`
    - **Описание:** Сохраняет значение из регистра источника в память по адресу, вычисленному как сумма смещения и базового регистра.
    - **Действие:** `M[offset + rs1] <- rs2`

- **Store Byte**
    - **Синтаксис:** `sb <rs2>, <offset>(<rs1>)`
    - **Описание:** Сохраняет младшие 8 бит значения из регистра источника в память по адресу, вычисленному как сумма смещения и базового регистра.
    - **Действие:** `M[offset + rs1] <- rs2 & 0xFF`

- **Load Word**
    - **Синтаксис:** `lw <rd>, <offset>(<rs1>)`
    - **Описание:** Загружает слово из памяти по адресу, вычисленному как сумма смещения и базового регистра, в регистр назначения.
    - **Действие:** `rd <- M[offset + rs1]`

- **Load Byte**
    - **Синтаксис:** `lb <rd>, <offset>(<rs1>)`
    - **Описание:** Загружает байт из памяти по адресу, вычисленному как сумма смещения и базового регистра, расширяет его со знаком до 32 бит и сохраняет в регистре назначения.
    - **Действие:** `rd <- signext(M[offset + rs1][7:0])`

### Арифметические инструкции

- **Add Immediate**
    - **Синтаксис:** `addi <rd>, <rs1>, <k>`
    - **Описание:** Складывает 12‑битное знаково‑расширенное непосредственное значение со значением регистра источника и сохраняет результат в регистре назначения. Непосредственное `k` усекается до 12 бит и расширяется знаком до 32 бит перед сложением.
    - **Действие:** `rd <- rs1 + signext(k[11:0])`

- **Set Less Than Immediate**
    - **Синтаксис:** `slti <rd>, <rs1>, <k>`
    - **Описание:** Устанавливает регистр назначения в 1, если значение регистра источника меньше непосредственного значения (знаковое сравнение), иначе в 0.
    - **Действие:** `rd <- (rs1 < k) ? 1 : 0`

- **Add**
    - **Синтаксис:** `add <rd>, <rs1>, <rs2>`
    - **Описание:** Складывает значения двух регистров источников и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 + rs2`

- **Subtract**
    - **Синтаксис:** `sub <rd>, <rs1>, <rs2>`
    - **Описание:** Вычитает значение второго регистра источника из первого и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 - rs2`

- **Multiply**
    - **Синтаксис:** `mul <rd>, <rs1>, <rs2>`
    - **Описание:** Умножает значения двух регистров источников и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 * rs2`

- **Multiply High**
    - **Синтаксис:** `mulh <rd>, <rs1>, <rs2>`
    - **Описание:** Умножает значения двух регистров источников и сохраняет старшую часть результата в регистре назначения.
    - **Действие:** `rd <- (rs1 * rs2) >> (разрядность слова)`

- **Divide**
    - **Синтаксис:** `div <rd>, <rs1>, <rs2>`
    - **Описание:** Делит значение первого регистра источника на значение второго и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 / rs2`

- **Remainder**
    - **Синтаксис:** `rem <rd>, <rs1>, <rs2>`
    - **Описание:** Вычисляет остаток от деления значения первого регистра источника на второй и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 % rs2`

### Побитовые инструкции

- **Logical Shift Left Immediate**
    - **Синтаксис:** `slli <rd>, <rs1>, <k>`
    - **Описание:** Сдвигает значение регистра источника влево на величину, заданную непосредственным значением (младшие 5 бит), и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 << (k & 0x1F)`

- **Logical Shift Right Immediate**
    - **Синтаксис:** `srli <rd>, <rs1>, <k>`
    - **Описание:** Сдвигает значение регистра источника вправо логически (заполнение нулями) на величину, заданную непосредственным значением (младшие 5 бит), и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 >>> (k & 0x1F)`

- **Arithmetic Shift Right Immediate**
    - **Синтаксис:** `srai <rd>, <rs1>, <k>`
    - **Описание:** Сдвигает значение регистра источника вправо арифметически (сохранение знака) на величину, заданную непосредственным значением (младшие 5 бит), и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 >> (k & 0x1F)`

- **Logical Shift Left**
    - **Синтаксис:** `sll <rd>, <rs1>, <rs2>`
    - **Описание:** Сдвигает значение первого регистра источника влево на количество бит, заданное младшими 5 битами второго регистра источника, и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 << (rs2 & 0x1F)`

- **Logical Shift Right**
    - **Синтаксис:** `srl <rd>, <rs1>, <rs2>`
    - **Описание:** Сдвигает значение первого регистра источника вправо логически на количество бит, заданное младшими 5 битами второго регистра источника, и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 >> (rs2 & 0x1F)`

- **Arithmetic Shift Right**
    - **Синтаксис:** `sra <rd>, <rs1>, <rs2>`
    - **Описание:** Сдвигает значение первого регистра источника вправо арифметически на количество бит, заданное младшими 5 битами второго регистра источника, и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 >> (rs2 & 0x1F)`

- **Bitwise AND**
    - **Синтаксис:** `and <rd>, <rs1>, <rs2>`
    - **Описание:** Выполняет побитовое И над значениями двух регистров источников и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 & rs2`

- **Bitwise AND Immediate**
    - **Синтаксис:** `andi <rd>, <rs1>, <k>`
    - **Описание:** Выполняет побитовое И над значением регистра источника и 12‑битным знаково‑расширенным непосредственным значением.
    - **Действие:** `rd <- rs1 & signext(k[11:0])`

- **Bitwise OR**
    - **Синтаксис:** `or <rd>, <rs1>, <rs2>`
    - **Описание:** Выполняет побитовое ИЛИ над значениями двух регистров источников и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 | rs2`

- **Bitwise OR Immediate**
    - **Синтаксис:** `ori <rd>, <rs1>, <k>`
    - **Описание:** Выполняет побитовое ИЛИ над значением регистра источника и 12‑битным знаково‑расширенным непосредственным значением.
    - **Действие:** `rd <- rs1 | signext(k[11:0])`

- **Bitwise XOR**
    - **Синтаксис:** `xor <rd>, <rs1>, <rs2>`
    - **Описание:** Выполняет побитовое исключающее ИЛИ над значениями двух регистров источников и сохраняет результат в регистре назначения.
    - **Действие:** `rd <- rs1 ^ rs2`

- **Bitwise XOR Immediate**
    - **Синтаксис:** `xori <rd>, <rs1>, <k>`
    - **Описание:** Выполняет побитовое исключающее ИЛИ над значением регистра источника и 12‑битным знаково‑расширенным непосредственным значением.
    - **Действие:** `rd <- rs1 ^ signext(k[11:0])`

### Инструкции управления потоком

- **Jump**
    - **Синтаксис:** `j <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения.
    - **Действие:** `pc <- pc + k`

- **Jump and Link**
    - **Синтаксис:** `jal <rd>, <k>`
    - **Описание:** Сохраняет адрес следующей инструкции в регистре назначения и выполняет переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения.
    - **Действие:** `rd <- pc + 4, pc <- pc + k`

- **Jump Register**
    - **Синтаксис:** `jr <rs>`
    - **Описание:** Переход по адресу, хранящемуся в регистре источника.
    - **Действие:** `pc <- rs`

- **Branch if Equal to Zero**
    - **Синтаксис:** `beqz <rs1>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если значение в регистре источника равно нулю.
    - **Действие:** `if rs1 == 0 then pc <- pc + k`

- **Branch if Not Equal to Zero**
    - **Синтаксис:** `bnez <rs1>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если значение в регистре источника не равно нулю.
    - **Действие:** `if rs1 != 0 then pc <- pc + k`

- **Branch if Greater Than**
    - **Синтаксис:** `bgt <rs1>, <rs2>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если значение в первом регистре источника больше значения во втором регистре источника.
    - **Действие:** `if rs1 > rs2 then pc <- pc + k`

- **Branch if Less Than or Equal**
    - **Синтаксис:** `ble <rs1>, <rs2>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если значение в первом регистре источника меньше или равно значению во втором регистре источника.
    - **Действие:** `if rs1 <= rs2 then pc <- pc + k`

- **Branch if Greater Than (Unsigned)**
    - **Синтаксис:** `bgtu <rs1>, <rs2>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если беззнаковая интерпретация первого регистра источника больше беззнаковой интерпретации второго регистра источника.
    - **Действие:** `if unsigned(rs1) > unsigned(rs2) then pc <- pc + k`

- **Branch if Less Than or Equal (Unsigned)**
    - **Синтаксис:** `bleu <rs1>, <rs2>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если беззнаковая интерпретация первого регистра источника меньше или равна беззнаковой интерпретации второго регистра источника.
    - **Действие:** `if unsigned(rs1) <= unsigned(rs2) then pc <- pc + k`

- **Branch if Equal**
    - **Синтаксис:** `beq <rs1>, <rs2>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если значение в первом регистре источника равно значению во втором регистре источника.
    - **Действие:** `if rs1 == rs2 then pc <- pc + k`

- **Branch if Not Equal**
    - **Синтаксис:** `bne <rs1>, <rs2>, <k>`
    - **Описание:** Переход по адресу, вычисленному как сумма текущего счётчика команд и непосредственного значения, если значение в первом регистре источника не равно значению во втором регистре источника.
    - **Действие:** `if rs1 != rs2 then pc <- pc + k`

- **Halt**
    - **Синтаксис:** `halt`
    - **Описание:** Остановка машины.

## Специфические представления состояния ISA

- `<reg>:dec`, `<reg>:hex` — просмотр значения конкретного регистра в десятичном или шестнадцатеричном формате.

Доступные регистры: `Zero`, `Ra`, `Sp`, `Gp`, `Tp`, `T0`, `T1`, `T2`, `S0Fp`, `S1`, `A0`, `A1`, `A2`, `A3`, `A4`, `A5`, `A6`, `A7`, `S2`, `S3`, `S4`, `S5`, `S6`, `S7`, `S8`, `S9`, `S10`, `S11`, `T3`, `T4`, `T5`, `T6`.
